# TronZap

TronZap operates a publicly documented REST API for renting/purchasing TRON blockchain Energy (and bandwidth) to reduce USDT (TRC-20) transfer fees. The JSON/HTTPS RPC-style API is backed by official PHP, Node.js, and Python SDKs and a publicly linked Postman collection.
