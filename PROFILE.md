# TronZap

API-first TRON-network infrastructure provider offering automated TRON Energy and Bandwidth rental, energy subscriptions, and AML crypto checks to reduce USDT (TRC-20) transfer costs via delegation to non-custodial wallets.

## APIs

- **TronZap REST API** — REST API for TRON Energy and Bandwidth rental, energy subscriptions, and AML crypto checks. Endpoints include Get Services, Check Balance, Estimate Energy, Address Info, Calculate Resource Cost, Create/Check Transaction, subscription lifecycle, and AML checks. Bearer token + SHA256 X-Signature authentication. (`https://api.tronzap.com/v1/`)

> Publicly documented REST API at https://api.tronzap.com/v1/ with Bearer token + SHA256 X-Signature auth, backed by a public Postman collection and official PHP/Node.js/Python SDKs (GitHub org tron-energy-market). Partial agent-native surface: TronZap publishes an llms.txt at https://tronzap.com/llms.txt (verified 2026-08-30); no MCP server and no provider-published agent skills were found. The submitted apis.json at https://docs.tronzap.com/apis.json lists the docs host as baseURL, but the callable API host is api.tronzap.com. No OpenAPI/AsyncAPI/GraphQL contract is published, but a first-party public Postman Collection v2.0.0 is (https://www.postman.com/tron-energy/tronzap-com/overview). A second, fully public API — the Wallet Orders API at https://docs-wallets.tronzap.com/api/ — was found on re-profile.
